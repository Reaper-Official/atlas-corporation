📋 Préparation et Objectifs

Objectif : Obtenir une évaluation fiable et complète des performances de votre PC Windows.

  • Ne PAS désactiver Windows Defender - laissez-le actif
  • Fermer tous les programmes inutiles avant de commencer
  • Assurez-vous que votre PC est branché sur secteur (pour les laptops)
  • Prévoyez environ 1 à 2 heures pour l'ensemble des tests
1

Test Général avec UserDiag

UserDiag effectue un diagnostic complet de votre système directement en ligne.

📥 Procédure :

  • Visitez le site officiel : https://userdiag.com
  • Lancez le test rapide en ligne (directement dans le navigateur)
  • Une fois le test terminé, copiez le lien du rapport généré
  • Conservez ce lien pour référence future
💡 Important : Pas besoin de télécharger de logiciel, le test se fait directement en ligne. Conservez simplement le lien du rapport !
🌐 Accéder à UserDiag
2

Benchmark Graphique avec 3DMark

3DMark est la référence mondiale pour tester les performances graphiques.

🎮 Procédure :

  • Ouvrez Steam
  • Recherchez 3DMark dans le store
  • Installez la version démo (gratuite)
  • Lancez le test par défaut (Time Spy recommandé)
  • Prenez une capture d'écran des résultats à la fin du test
⚠️ Attention : Le test peut durer plusieurs minutes et solliciter intensément votre GPU.
🎮 Télécharger 3DMark
3

Vérification du Stockage avec CrystalDiskInfo

CrystalDiskInfo analyse l'état de santé de vos disques durs et SSD.

💾 Procédure :

  • Téléchargez depuis : crystalmark.info
  • Installez et lancez le logiciel
  • Vérifiez en priorité l'état du SSD contenant Windows
  • Contrôlez ensuite les autres disques
  • Exportez les résultats ou faites une capture d'écran

Indicateurs à surveiller : Température, état de santé, heures d'utilisation

💾 Télécharger CrystalDiskInfo
4

Monitoring Matériel avec MSI Afterburner & RivaTuner

MSI Afterburner (avec RivaTuner) permet d'afficher en temps réel les performances de votre PC pendant une session de jeu intensive.

📊 Procédure :

  • Téléchargez et installez MSI Afterburner depuis : Site officiel MSI (RivaTuner est inclus dans l'installation)
⚠️ Important lors de l'installation :
  • Téléchargez la version "Final Release" ou "Released" (PAS les versions Beta)
  • Ne modifiez PAS le répertoire d'installation par défaut - gardez C:\Program Files (x86)\MSI Afterburner\
  • Sinon, le script automatique de configuration ne trouvera pas le bon emplacement !
🚨 ATTENTION CRITIQUE :

Lors de l'installation, DÉCOCHEZ l'option d'installation de Norton Antivirus ! Norton est le pire antivirus existant selon nos analyses - il ralentit drastiquement votre système et interfère avec les benchmarks.

  • Importez la configuration personnalisée (voir section ci-dessous)
  • Activez l'affichage à l'écran (OSD) pour monitorer :
    • Températures CPU / GPU
    • Fréquences et taux d'utilisation
    • FPS en temps réel
    • Utilisation RAM et VRAM
⚙️ Télécharger MSI Afterburner

🎮 Test Intensif Obligatoire (10 minutes minimum)

⚠️ Protocole de Test Important :

Pour obtenir des résultats représentatifs, vous devez :

  • MSI Afterburner doit être lancé, mais doit rester en arrière-plan (ne doit PAS être l'application au premier plan)
  • Le jeu doit être l'application au premier plan - c'est lui qui doit avoir le focus
  • MSI Afterburner affichera automatiquement l'OSD (affichage à l'écran) sur le jeu
  • Lancer un jeu exigeant (AAA récent ou jeu que vous utilisez régulièrement)
  • Activer l'enregistrement vidéo (OBS, NVIDIA ShadowPlay, AMD ReLive, etc.) pour simuler une charge processeur plus lourde
  • Jouer pendant au moins 10 minutes en conditions réelles
  • Vérifier que toutes les données sont visibles à l'écran (températures, FPS, utilisation CPU/GPU)
  • Prendre plusieurs captures d'écran pendant la session
💡 Pourquoi l'enregistrement est important ?

L'enregistrement vidéo active le décodeur et sollicite davantage le CPU, simulant ainsi la charge des jeux AAA modernes qui utilisent plusieurs threads simultanément. Cela permet d'évaluer les performances en conditions réelles d'utilisation intensive.

⚙️ Configuration Automatique de MSI Afterburner

Pour gagner du temps, utilisez notre configuration pré-paramétrée qui affiche toutes les informations essentielles à l'écran.

📦 Méthode Manuelle

  1. Téléchargez le fichier de configuration :
    https://fichiers.atlas-corporation.fr/MSIAfterburner.cfg
  2. Copiez ce fichier dans le dossier :
    C:\Program Files (x86)\MSI Afterburner\Profiles
  3. Redémarrez MSI Afterburner pour appliquer les réglages

🤖 Installation Automatique avec Script

Cliquez sur le bouton ci-dessous pour télécharger automatiquement le script d'installation. Ensuite, exécutez-le en tant qu'administrateur (clic droit → "Exécuter en tant qu'administrateur").

⚙️ Télécharger la Config Manuellement

📝 Contenu du Script

Le script télécharge automatiquement le fichier de configuration et le place dans le dossier adéquat :

@echo off
echo Téléchargement de la configuration MSI Afterburner...
set "cfg_url=https://fichiers.atlas-corporation.fr/MSIAfterburner.cfg"
set "dest=C:\Program Files (x86)\MSI Afterburner\Profiles\MSIAfterburner.cfg"

powershell -Command "Invoke-WebRequest '%cfg_url%' -OutFile '%dest%'"

if exist "%dest%" (
    echo Configuration installée avec succès dans "%dest%".
) else (
    echo Erreur : impossible d'installer la configuration.
)
pause

💡 Astuce : Faites un clic droit sur le fichier .bat → "Exécuter en tant qu'administrateur"

✅ Conseils pour des Résultats Optimaux

  • Fermez tous les programmes en arrière-plan (navigateurs, clients de jeux, Discord, etc.) sauf pour le test RivaTuner
  • Notez les versions de vos pilotes graphiques (NVIDIA ou AMD)
  • N'exécutez qu'un seul benchmark à la fois
  • Attendez que le PC soit à température stable avant de commencer
  • Gardez Windows Defender actif - ne le désactivez pas
  • Assurez-vous que le mode de performance est réglé sur "Performances maximales"
  • Vérifiez que votre PC n'est pas en mode économie d'énergie
  • Pour le test RivaTuner : utilisez un logiciel d'enregistrement pour charger le CPU (OBS, ShadowPlay, ReLive)

📁 Résultats à Conserver

À la fin de tous les tests, conservez les fichiers et captures suivants :

  • ✔️ Lien du rapport UserDiag (copié depuis le site web)
  • ✔️ Résultats 3DMark (captures d'écran + score)
  • ✔️ Informations CrystalDiskInfo (capture ou export)
  • ✔️ Captures d'écran RivaTuner / Afterburner pendant les 10 minutes de jeu intensif (avec enregistrement actif et toutes les données visibles)
  • ✔️ Vidéo de l'enregistrement de la session de jeu (optionnel mais recommandé)

Conseil : Créez un dossier dédié avec la date du benchmark pour tout archiver (exemple: "Benchmark_PC_11-10-2025").
