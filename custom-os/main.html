Nous avons choisi Windows 11 Famille pour éviter les vulnérabilités critiques présentes dans Windows 11 Pro.

⚠️ Vulnérabilité Windows 11 Pro - Port 3389

Niveau de risque : 8.1/10

Le Bureau à Distance (RDP) de Windows 11 Pro présente des failles critiques :

  • CAS 1 : Création de comptes administrateur via script + exposition UPNP

Solution : Windows 11 Famille limite ces risques en ne permettant que les demandes de connexion sortantes.

Alternative - Installation Manuelle

1. Préparation de la Clé USB

Téléchargez l'application : Ventoy
• Selectionnez la version .zip
• Extrayez la.
• Ouvrez Ventoy2Disk.exe, sélectionnez votre clé USB, puis cliquez sur "Installer" et confirmez deux fois en cliquant sur "Oui"
• Une fois l’installation terminée, fermez simplement le logiciel

2. Installation Windows 11

• Si vous voulez l'IMAGE de Microsoft, allez sur leur site
• Si vous souhaitez tester celle d'atlas-corporation, voici le lien Indisponible
• Dans les 2 cas, à la fin du téléchargement de l'ISO, veuillez le copier dans le répertoire Ventoy

Configuration BIOS

3. Accès au BIOS

• Redémarrez le PC
• Appuyez rapidement (spammer) sur DEL ou F2
• Accédez au mode "Advanced Mode"
• Rendez-vous dans l'onglet "Boot" ou "Démarrage"

4. Ordre de Démarrage

• Placez votre clé USB en premier dans l'ordre de démarrage
• Sauvegardez et quittez via "Save and Exit"

🔐 Configuration Secure Boot

OS Type : Windows UEFI Mode
Secure Boot Mode : Standard (clés Microsoft par défaut)

• Choisissez "Other OS" uniquement si vous installez un système non signé comme un Linux personnalisé

Résolution des Problèmes de Disque

Si le disque n'est pas reconnu

Appuyez sur Shift + F10 pour ouvrir l'invite de commandes, puis exécutez :

diskpart
list disk
select disk 0 (remplacez 0 par le chiffre de votre disque)
clean
convert gpt
create partition primary
format fs=ntfs quick
assign letter=C
exit

Ensuite, supprimez la partition avec l’icône en croix rouge dans l’installateur Windows, puis cliquez sur "Suivant".
